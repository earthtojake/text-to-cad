# PERFORMANCE.md — build / edit timings for the W16 (record-keeping only)

Purpose: see whether and where cadgen's caches (memo scopes, package store,
warm daemon, mesh ledger) are hit as the model grows. No tuning is done here;
this is a log. Times are wall-clock on the dev Mac (10 cores, 64 GB), measured
with `time` or the `--verbose` stage lines. Other builds/renders were often
running concurrently (parallel builder agents), so treat single numbers as
indicative.

How to read a row: **what changed** since the previous build → which memo
scopes must re-run; **cache** = what the log says (`current` = no-op,
`built` = pipeline ran; "memo hit" = a module's scope was served from cache).
