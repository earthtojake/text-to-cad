# Raptor 2 Reconstruction — Render Suite

> **Educational, non-functional public-source reconstruction. Not suitable for
> manufacture, propulsion, testing, or operational engineering.**

Generated from the three `.step.py` models via the CAD skill snapshot tool
(1920×1440), plus PIL leader-line annotation (`../annotate_renders.py`).

| File | View |
|---|---|
| `hero_three_quarter.png` | Cinematic 3/4 hero view, material shading |
| `ortho_front.png` / `ortho_right.png` / `ortho_top.png` | Orthographic technical exterior |
| `nozzle_bottom.png` | Bottom / nozzle view (dark interior, throat) |
| `cutaway_front_ortho.png` | Orthographic schematic cutaway (opening toward +Y) |
| `cutaway_three_quarter.png` | Perspective cutaway view |
| `cutaway_annotated.png` | Labeled cutaway with leader lines + disclaimer |
| `exterior_annotated.png` | Labeled exterior orthographic view |
| `transparent_overlay.png` | Transparent structure overlay |
| `exploded_iso.png` / `exploded_front.png` | Exploded educational views |

A Raptor 1/2/3 variant-comparison render was deliberately **not** produced:
only Raptor 2 exterior geometry is supported by the collected public imagery
at reconstruction fidelity (see `../RESEARCH.md` §5 for the sourced
comparison table instead).
