# Mesh Exports

Durable exported mesh artifacts, organized by format rather than by source
model:

- `stl/`
- `3mf/`
- `glb/`

Files here are exports of models that live under
[`../step/parts/`](../step/parts/README.md) or
[`../step/assemblies/`](../step/assemblies/README.md) — kept as fixtures for
exercising export and viewer/render behavior, not as the canonical source for
any model. Regenerate with the `cad` skill's export CLI rather than hand-editing
these files.
