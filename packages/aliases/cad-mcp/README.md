# cad-mcp

`cad-mcp` is an alias of `cad`, still published at every release. This distribution holds
nothing of its own but its command: it installs `cad` at the same release, which carries the
stdio transport an agent app starts for the CAD app, and keeps the `cad-mcp` command that runs it.

Install `cad` instead. The install command at https://texttocad.dev installs it.
