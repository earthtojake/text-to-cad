# cad-server

`cad-server` is an alias of `cad`, still published at every release. This distribution holds
nothing of its own but its command: it installs `cad` at the same release, which carries the CAD
server and the viewer, and keeps the `cad` command it always had, so a tool installed as
`cad-server` keeps it.

Install `cad` instead. The install command at https://texttocad.dev installs it.
