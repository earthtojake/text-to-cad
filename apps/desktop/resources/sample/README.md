# Hardcore sample

A place to try Hardcore without picking a folder of your own.

- `l_bracket.py` is the script that builds the part. The sizes are at the top.
- `l_bracket.step` is the part it builds. Open it to see it in the viewer.

Some things to ask the agent:

- "Make the bracket 20 mm taller and add a third hole to the back."
- "Add a slot to the base instead of the two round holes."
- "Export an STL I can 3D print."
