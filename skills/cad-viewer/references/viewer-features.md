# CAD Viewer Features

Load this only when a task needs Viewer file-support details or UI control guidance.

## Supported Files

- `.step`, `.stp`: STEP/STP review through the document's tree in the store (compiled from the file's bytes on open when missing); supports assembly trees, part hide/show, inspect/focus, face/edge/vertex/part selection, copied `#...` CAD references, display modes, clip planes, and a live Kinematics tab (named poses and joint sliders) when the model's sidecar declares kinematics, plus animation clips through the Animate tool when it declares animation.
- `.stl`, `.3mf`, `.glb`: mesh viewing with orbit/pan/zoom, screenshots, and the Display tab's shading modes. Measure is not offered — it is a STEP-only tool that snaps to B-rep topology, which a mesh has none of. A plain GLB's `COLOR_0` vertex colors render as source colors, exactly like authored material colors; a GLB carrying embedded animation plays it through the Animate tool, not a tab of its own, and looks the same at rest and while animating: a GLB is always drawn as its own glTF scene, wearing the viewer's surface finish outside Render mode (keeping its colors, maps and opacity) and its authored finish in Render mode.
- `.dxf`: read-only 3D flat-pattern viewing. The drawing file is parsed directly and rendered client-side — no render artifact exists for a `.dxf`, so generated and imported drawings alike render straight from their own bytes.
- `.urdf`: robot link/mesh viewing with movable joint sliders, and reset pose.
- `.srdf`: paired-URDF viewing with planning groups, group-state presets, and joint controls.
- `.sdf`: SDF model/world viewing with metadata, counts, and joint controls when available.

## Controls

- Navigation: left-drag to orbit, right/middle-drag or Shift-drag to pan (two fingers on touch), wheel or pinch to zoom, and Arrow/WASD keys to orbit. Use the view sphere for top/bottom/front/back/left/right views; click its center for the default isometric view.
- File browser: toggle the left CAD Viewer sidebar, search files/ids/paths, expand folders, select entries, or switch files from the breadcrumb menus.
- File names read exactly as they do on disk. The tab title, breadcrumb, catalog rows and the file picker all show the artifact's own basename and its own path — `moonwatch.step`, never the `moonwatch.py` that generated it. The Viewer never learns whether a document was generated: its status badge is one of not compiled / compiling / rendered / failed, decided from the file's bytes, the store and the build pool's job ledger, and no part of the UI names or opens a model script. (Copied topology references are the one exception, and a deliberate one: see the bare-stem rule below.)
- Floating toolbar: a robot description opens in `Pose`, leftmost in its toolbar — it drags the robot's joints by knobs in the viewport, and is the tool a robot always starts in. A STEP file with kinematics offers `Pose` too, sitting immediately left of `Animate`, but opens in `Select` instead. A mesh file (GLB, STL, 3MF) or a DXF opens in `Orbit`, a plain view tool that only moves the camera: these have nothing to pick, so they have no `Select` — only `Draw` beside it, plus `Animate` for a GLB with clips. `Select` orbits the model and picks: faces, edges and parts on a STEP file; whole links on a robot description, where it has its own icon and `Escape` clears the selection; a selection exists only while Select is active (choosing another tool clears it, and selecting from the sidebar returns to Select). There is no Pan tool: right-drag, Shift-drag or two fingers pan the camera under every tool. `Measure` is STEP-only — it snaps to B-rep topology, so no mesh, drawing or robot offers it; pressing it again opens its snap menu, and recorded measurements list in a compact panel under the toolbar. `Draw` opens the sketch tools. `Animate`, the rightmost tool, appears only when the model has animation routines: it disables picking and puts a playbar at the bottom of the viewport (routine list when there is more than one, play/pause, scrubber, and a settings menu with Speed — shown as e.g. `1×` — and Loop); leaving the tool returns the model to its posed state. Every pose change — a named pose, a slider, a typed value, or a Pose knob drag — is an instant jump; there is no eased transition. `Copy screenshot` puts a viewport capture on the clipboard — screenshots are clipboard-only; nothing downloads. A DXF's 2D/3D switch is a navbar action beside Take snapshot (`Switch to 2D view` / `Switch to 3D view`); 2D is a locked plan view: orthographic, no view cube, left-drag pans, and it cannot be tilted. `Fullscreen` hands the model the whole window: a model with routines is locked in the Animate tool with the same playbar, and the corner settings hold only orbit options (neither the settings button nor its Speed label has a tooltip).
- File context menu (file browser rows and the breadcrumb): `Reveal in Explorer View` highlights the entry in the file browser, and the copy items hand out references to the file — `Copy Filename`, `Copy Path` (absolute), `Copy Relative Path` (relative to the served directory), and `Copy Link`, which copies the viewer deep link for the entry (the bare origin plus `?file=<root-relative path>`, byte-identical to the URL the app itself lands on). There is no download and no native file-manager reveal; paths and links are how bytes leave the Viewer.
- Drawing tools: `Draw` locks the view direction and lays an Excalidraw sketch over the model; pan and zoom still work and the sketch moves with the model. A second toolbar row offers select/move, pen, line, arrow, rectangle, ellipse, text, eraser, undo, redo and clear. `Copy Drawing` copies the view with the sketch; leaving `Draw` discards the sketch.
- File sheet: open the right sheet for file-specific tabs. STEP files get Features (the model tree, with a `Filter model…` search whose hits select in the viewport and are revealed in the tree when the search ends, and the selection's Reference at its foot), Kinematics when the document's sidecar declares kinematics (a named-pose dropdown, then joint sliders — a DOF that exactly one coupling gears is marked "driven by <coupling>": its slider shows the effective value and drags the coupling, so sliding one member of a gear train turns the whole train — then Reset), and Display. Animation is not a tab: it is the Animate tool, and a render module's load errors surface as a viewport alert. URDF/SRDF files get Kinematics (always leftmost, and the tab the sheet lands on; a named-pose or group-state dropdown then joint sliders, then Reset), Links (the link tree: rows carry no icon, and a `Filter links…` search also matches joint names; hover and click highlight the link in the viewport; a single root with children is pinned — no chevron, no indent, its children start at the tree's own left edge; a root that is only a frame with one fixed-jointed child, such as `base_footprint`, gets no row of its own and its child leads the tree instead, unless the description has no content anywhere; and a Reference pane — opening at a third of the tab height, never below a readable minimum, and never so tall the tree loses its own, the same split the STEP Features tree uses — with the link's mass, centre of mass and inertia, its visual and collision geometry, the parent joint's axis, limits and origin, and SRDF groups; a mesh path there opens that mesh file, and a parent or child link name selects that link) and Display; SDF adds its own SDF metadata tab after Links. Mesh files (STL, 3MF, GLB) have only a Display tab, and their sheet starts closed. DXF drawings get Material, Bends when the drawing has bend lines, Layers when it uses layers, and Display.
- Viewing mode: the navbar dropdown selects a preset: `Solid`, `Render`, `X-ray`, `Hidden line`, or `Wireframe`. Solid is the default. Render starts with perspective projection; the other presets start orthographic. The same Display tab remains available in every preset, with Camera, Surfaces, Edges, Lighting, Background, Floor, Grid, and Axes controls. A change from a preset shows `Custom`; choosing another preset or resetting restores its defaults. Clip and Explode remain independent inspection tools and survive those actions. Edges, Clip, Explode, the X-ray, Hidden line and Wireframe presets and the Hidden/Off surface styles belong to STEP models: every other file type offers only `Solid` and `Render` with Shaded or Flat surfaces, and the snapshot CLIs refuse the same settings for those types.
- Copied references carry their file: the Viewer prefixes every copied ref with the shortest
  path suffix that names that file uniquely (`bracket#o1.2.f1`, or
  `lyra/STEP/palm.step#o1.3` where a filename is not unique), so a ref pasted into a prompt
  still says which model it belongs to. A generated model shows as a bare stem — the common
  case, so it gets the shortest name — while everything else keeps its suffix (`bracket.step`,
  `plate.stl`, `plate.3mf`). That means a bare stem is NOT a literal path suffix, so resolving
  one back to a file means expanding it; the CAD skill's
  `references/inspection-and-validation.md` documents the split-and-expand steps. Bare `#...`
  refs remain valid everywhere.
- Tutorial tips: the first time a selection produces a copyable reference — a component, a subassembly, or a face/edge — a one-shot tip above the "Copy #…" button explains that references can be pasted into prompts to edit specific parts. Only its X closes it; clicking away, Escape, and reloads leave it to reappear on the next selection, and once dismissed it never returns. Append `?resetTips=1` to a Viewer URL to clear the record and re-arm every tip; the param applies once and is stripped from the address bar.
- Display tab: Mode and projection selectors are followed by the view's controls. Each group has an enable switch; its parameters are available while enabled. Lighting, floor, background and guides can be combined with any preset. Appearance can follow the host or use Light/Dark. Background and floor have color and opacity controls. Floor placement chooses the document origin (default) or the model's lowest point.
- Exploded view: one percentage slider — 0% is assembled, and any higher value pulls the assembly apart. It is disabled for a document with fewer than two explodable parts.
- Clip: a Flip toggle and X/Y/Z position sliders, always visible — a slider at 0 means no cut on that axis.
