# CAD Viewer 功能

仅当任务需要 Viewer 文件支持详情或 UI 控件指引时加载本文件。

## 支持的文件

- `.step`、`.stp`：通过隐藏的 GLB 附带附带产物（sidecar）进行 STEP/STP 评审；支持装配体（assembly）树、零件（part）隐藏/显示、检查/聚焦、面/边/顶点/零件（part）选择、复制的 `#...` CAD 引用、显示模式、剖切平面，以及当附带附带产物（sidecar）模块存在时可选的 STEP 模块参数/动画。
- `.stl`、`.3mf`、`.glb`：网格（mesh）查看，支持环绕/平移/缩放、截图、外观控件，以及可用时的实体/线框显示。
- `.dxf`：只读平板图查看，当折弯预览数据可用时，还支持板厚和折弯方向/角度控件。
- `.gcode`：诊断性刀轨预览；显示按层着色的挤出条带、可选的空行程移动、可见层和细节控件、特征标记、运动统计、边界和解析器警告。它不执行重新切片、不模拟固件，也不替代 G-code 验证（validation）。
- `.urdf`：机器人连杆（link）/网格（mesh）查看，支持可动关节（joint）滑块、位姿（pose）重置和复制的关节（joint）值。
- `.srdf`：关联 URDF 查看，支持规划组、组状态预设、关节（joint）控件，以及可选的 MoveIt2 IK/规划控件。
- `.sdf`：SDF 模型/世界查看，支持元数据、计数、警告，以及可用时的关节（joint）控件。

## 控件

- 导航：左键拖动环绕，右键/中键拖动平移，滚轮或捏合缩放，Arrow/WASD 键环绕。使用视角球切换上/下/前/后/左/右视图；点击其中心恢复默认等轴测视图。
- 文件浏览器：切换左侧 CAD Viewer 侧边栏，搜索文件/id/路径，展开文件夹，选择条目，或从面包屑菜单切换文件。
- 浮动工具栏：`Select` 复制 STEP 拓扑（topology）引用，`Draw` 打开标注工具，`Select Pose` 在可用时用于机器人目标拾取，`Open orbit preview` 启动自动旋转预览，复制/下载按钮用于截图。
- 绘图工具：自由手绘、直线、箭头、展开、矩形、圆形、填充、橡皮擦、撤销、重做和清除。
- 文件面板：打开右侧面板以使用文件特定控件，例如 STEP 树/参数、G-code 层/细节/空行程、DXF 厚度/折弯、URDF/SRDF/SDF 关节（joint）和元数据，以及显示和外观控件。
- 显示/外观：使用文件面板和主题菜单切换实体/线框/X 射线模式、STEP 剖切、用于动画式垂直 STEP 拆解的独立 Explode 开关、表面颜色、边可见性/细节、高亮样式、背景、地板/网格（mesh）、光照、主题预设和颜色模式。
