# SendCutSend

溯源：维护于 [earthtojake/text-to-cad](https://github.com/earthtojake/text-to-cad)。
使用已安装的本地技能文件作为运行时真相来源；仓库链接仅用于溯源和发布审查。

使用此技能为 DXF 和 STEP/STP 文件生成保守的、有证据支撑的 SendCutSend 预检报告。

将 SendCutSend 的下单指南、目录 JSON 和规格 JSON 视为证据来源，而非稳定的 API。字段名称、类型和覆盖范围可能变化。不要将缺失、无法解析、`N/A` 或冲突的源数据转化为通过或失败。直接从官方 URL 获取源数据，仅使用本地检查代码测量特定文件事实；基于显式比较撰写最终报告。

## 几何检查

使用当前项目 Python 环境运行本地几何检查代码。如果 `$cad` 技能可用，优先使用它进行 STEP/STP/DXF 几何检查、测量和验证（validation）工作流（workflow），然后补充任何仍缺失的 SendCutSend 专项测量。当需要几何事实时，使用 `build123d.import_step` 进行 STEP/STP 检查，使用 `build123d.ezdxf` 进行 DXF 检查。不要使用原始文本解析或替代几何后端来获取几何事实。

## CAD 查看器交接（handoff）

完成创建或修改 `.dxf`、`.step` 或 `.stp` 上传候选文件的 SendCutSend 工作后，如果已安装 `$cad-viewer` 技能，必须始终将显式文件路径交接（handoff）给 `$cad-viewer`。`$cad-viewer` 必须在 CAD Viewer 未运行时启动它，并返回相关创建或更新文件的链接；如果 `$cad-viewer` 不可用或启动失败，应报告该情况，而不是静默省略交接（handoff）。

## 工作流（workflow）

1. 收集订单意图。
   - 激光板材切割和 2D 板材轮廓优先使用 DXF。
   - CNC 路由和 3D 模型上传工作流（workflow）优先使用 STEP/STP。
   - 记录文件类型、预期工艺、材料/SKU、厚度、数量、服务、表面处理和硬件。
   - 如果订单上下文缺失或模糊，检查足够的源数据以提出具体选项，然后在撰写就绪结论前请用户确认。包含候选 SKU/材料/厚度/服务及相关源链接；如有，包含来自规格 JSON 的 `photo_url` 图像和 `learn_more_url` 链接。
2. 阅读 `references/official-sources.md`，直接获取官方来源，然后检查返回的文档。防御性地规范化源事实：将数字字符串、尺寸字符串、`N/A`、缺失字段、混合类型和缺失服务数组解析为显式说明。
3. 在 `$cad` 可用时用它检查确切的上传文件，并使用针对性的 Python/`build123d` 补充任何缺失事实。不要仅检查源生成器、CAD 模型或生成器控制台摘要。
   - DXF：根据所选服务需要，测量单位、边界、图层、实体类型、开放/重复几何、不受支持的标注、候选孔/圆、线段统计、折弯线候选、折弯到切割距离、折弯相邻切割几何、局部法兰（flange）深度，以及退化零面积轮廓。
   - STEP/STP：根据所选服务需要，测量可解析性、单位提示、实体/曲面信号、边界框、壳/体信号、有效性、板材厚度（如有）、折弯范围内的圆柱折弯面半径，以及限制。
   - 保持每个检查助手仅报告事实。它可以报告测量、解析错误和限制，但不得输出通过/失败/就绪状态。
4. 按证据质量选择源记录。
   - 使用精确 SKU 作为唯一权威的目录/规格关联。
   - 如果仅提供材料和厚度，仅当候选匹配唯一且足够精确时才使用所选材料；否则列出候选并附源记录链接/图像，请用户选择。
   - 使用目录 JSON 判断可订购性：库存、切割工艺、可用服务、尺寸限制、硬件和表面处理。
   - 使用规格 JSON 获取工程值：公差、孔、桥接、折弯、攻丝、锪孔（countersink）、硬件压装、表面处理和材料属性。
   - 使用下单指南获取通俗语言的工作流（workflow）和通用文件格式规则。

## 比较

仅比较可信的证据对。

- 判断某项检查是否适用。
- 引用源字段路径或指南章节。
- 引用测量的文件事实。
- 仅当源要求和测量文件事实均可用且可信时才进行比较。
- 如果缺失某项测量或有风险，针对该具体几何事实编写小型针对性的 `build123d`/`ezdxf` 检查器。
- 将每个测量的上传风险、可制造性问题或引用的要求违规视为错误。不要推断任何替代的 SendCutSend UI 分类。
- 对于 DXF 单位，一起检查 `$INSUNITS`、标题范围、测量边界和订单上下文。如果 `$INSUNITS` 缺失、不受支持或不是 SendCutSend 指南预期的 DXF 单位代码（`1` 英寸或 `4` 毫米）之一，报告单位/比例错误，并建议在应用尺寸、法兰（flange）或材料专项比较前重新导出或确认单位。不要静默重新缩放几何或使用不确定的比例发出材料专项通过/失败检查。
- 对于带折弯线的 2D 文件，沿每条折弯线局部检查法兰（flange）长度。在每个跨度或采样点测量每条折弯线两侧最近的切割/自由边，包括打断折弯跨度或形成局部自由边的缺口、槽、间隙、分割凸耳和切口。将最小局部法兰（flange）深度与所选 SKU 的 `bending_specs.min_flange_length_before_bend` 和 `bending_specs.min_flange_length_after_bend` 进行比较。除非引用的源对该服务给出了孔到折弯或特征到折弯规则，否则不要将法兰（flange）长度限制应用于普通封闭孔或内部切口；按照引用规则要求，以中心线到折弯或边到折弯的测量单独报告这些情况。不要将附近的折弯相邻切割几何仅视为拐角 relief，除非剩余局部法兰（flange）仍通过法兰（flange）长度最小值。如果任何局部法兰（flange）深度低于 SKU 最小值，报告 `❌ fail`。当导出几何具有局部切口、打断折弯、分割折弯段、relief、凸耳或不受支撑区域时，不要依赖聚合的源级别值。
- 按物理原因分开报告折弯发现。不要将折弯相邻几何合并为通用法兰（flange）失败。为最小法兰（flange）/接触长度错误、折弯线或模具区域几何交叉、附近自由边或切口导致的折弯接触/支撑不足、不跨越折弯区域的折弯线、分割/共轴折弯段，以及接触或跨越折弯线的切割几何分别报告独立行。如果 SendCutSend 源未公开确切的模具区域/接触阈值，将测量的文件事实作为直接文件检查引用，并明确标记源受限的比较。
- 对于 STEP/STP 折弯零件（part），当模型包含钣金折弯几何或预期服务包括折弯时，检查折弯半径。尽可能使用 `$cad`/`build123d`/OCP 提取圆柱或环形折弯面及其半径，对重复折弯半径分组，并与所选 SKU 的 `bending_specs.effective_bend_radius` 或 `bending_specs.bend_radius` 比较。如果所选材料/SKU 未知，报告测量的折弯半径集，并在就绪结论前询问材料/厚度。如果测量半径与所选 SKU 工装半径冲突，报告折弯半径不匹配错误。

报告使用克制的状态标签：

- `✅ pass`：测量的文件事实满足引用的当前要求。
- `❌ fail`：测量的上传风险、可制造性问题，或直接测量到的引用当前要求违规。
- `❓ need more info`：缺失上下文、缺失源证据、未测量几何、源冲突或工具限制。

## 诊断图像

当发现通过视觉更容易理解时，如果图像生成或图像编辑能力可用，主动生成简洁的诊断图。使用生成或编辑的图像进行标注、图例和前后说明。每当出现 `❌ fail`、空间模糊的几何问题或需要前后说明的几何编辑时，无需等待用户要求即可执行。如果图像生成工具不可用，说明该限制并在报告中描述预期图表。

生成图像前，运行布局预检：

- 选择解释修复所需的最小标注集。
- 估计标签是否会拥挤几何、相互重叠或超出画布。如果可能拥挤，在生成前标记并切换为编号标记加侧边图例、更大画布或单独详图视图。
- 将较长的测量值和规则文本保留在图例中，不要直接放在密集几何上。
- 包含测量的失败距离、引用的最小值，以及建议的移动或间隙目标。

生成图像后，在交付前检查渲染的图像。如果标签重叠、被裁剪、难以阅读或遮挡几何，在报告前重新生成或修订图表。

## DXF 审查

对于激光板材切割，从刷新的来源和测量的 DXF 几何事实开始。

检查：

- 单一、可上传的 DXF 文件，模型几何为 1:1 比例
- 单位和整体零件（part）尺寸；在用户确认单位前，将缺失、不受支持或意外的 `$INSUNITS` 视为比例错误
- 服务要求封闭轮廓处的封闭切割轮廓
- 退化或零面积封闭轮廓、两点封闭多段线和奇数度切割端点
- 重复或重叠的切割几何
- 不受支持的标注、文本、尺寸、图像、构造线或隐藏指令图层
- 来自下单指南和上传工作流（workflow）的图层/颜色/线段约定
- 折弯线实体、折弯段长度、分割/共轴折弯、每条折弯线两侧的局部法兰（flange）深度、最近的非折弯切割边或切口距离、折弯线跨度覆盖、折弯接触/支撑不足、模具区域或折弯相邻切割几何交叉，以及折弯范围内折弯线接触或跨越时的切割几何
- 仅当源事实和测量文件事实均支持比较时，检查最小孔、槽、腹板宽度、内部几何、零件（part）密度、排样和间距
- 请求时检查折弯、攻丝、锪孔（countersink）、硬件、表面处理或去毛刺的二级服务要求

## STEP 审查

对于 CNC 路由或 3D 模型上传，从刷新的来源和测量的 STEP 几何事实开始。

检查：

- STEP/STP 文件可读性和实体体而非松散曲线或曲面
- 单位、比例、边界框、厚度和特征尺寸
- 折弯范围内的钣金折弯半径；将测量的圆柱折弯面半径与所选 SKU 的 `bending_specs.effective_bend_radius` 或 `bending_specs.bend_radius` 比较
- 仅当文件检查能测量该事实时，检查锐利内角、小孔/槽、薄壁、岛屿、深型腔（pocket）、刀具可达性和公差
- 几何是否代表更适合作为 DXF 激光切割的板材轮廓
- 材料、厚度、表面处理和二级服务兼容性

## 报告

包含文件路径、假定服务、材料/订单上下文、已检查的源文件及访问日期、检查的几何事实、按实际影响排序的发现，以及具体的后续编辑。在发现表格中，包含 `Rule source` 列，使用 Markdown 链接指向源 URL 以及该行使用的具体 JSON 字段路径或指南章节。如果某行仅基于直接文件检查且无外部规则，写 `Direct file inspection`；不要将源留空。除非每个要求的引用检查要么通过，要么明确不在所选服务范围内，否则不要称文件"SendCutSend ready"。

当结构化报告有帮助时，使用 `references/report-template.md`。
